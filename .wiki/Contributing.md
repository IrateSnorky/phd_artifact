# Contributing

## Workflow

- Keep backend and frontend changes aligned.
- Prefer small, focused commits.
- Add or update tests for behavior changes.
- Do not overwrite the original saved story during Office View transformations.

## Pull request checklist

- Backend tests pass.
- Frontend tests pass.
- Lint and build pass.
- AI-provider configuration is documented if you add a new provider or env var.
- Any survey or Office View behavior change includes a regression test.
